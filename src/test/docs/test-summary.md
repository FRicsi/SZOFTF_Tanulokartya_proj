# Tesztelési összegzés

## Elvégzett tesztelés

A projekt során manuális és automatizált tesztelés történt.

Az automatizált tesztelés:
- Vitest
- React Testing Library
- Playwright

technológiákkal valósult meg.

## Lefedett funkciók

- alkalmazás indulása
- tanulókártyák megjelenítése
- kártya megfordítása
- kártyák közti navigáció
- új kártya létrehozása
- üres űrlap kezelése
- alapvető felhasználói folyamatok
